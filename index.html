network-scanner

A multithreaded TCP port scanner. It sweeps a host for open ports, names the service behind each one, grabs version banners, and writes a JSON report.

Peer-to-Peer File Sharing System

C, Linux, TCP sockets · 3-person team — I built the peer program · April 2026

A BitTorrent-style system: a central tracker indexes files, and peers trade 1 KB chunks directly with each other over TCP. I owned the peer client end to end.

  • Download engine that pulls chunks in parallel across 4 worker threads, each thread claiming a distinct stride of the file so no chunk is fetched twice
  • Server thread that answers chunk requests from other peers, plus a thread that re-announces shared files to the tracker
  • MD5 verification of every completed file, and resume of interrupted downloads by reloading the partial file and skipping finished chunks
  • Tested with my teammates across a 13-peer Linux network, including peers dropping mid-transfer

Teammates built the tracker server and the build/demo tooling. Code is private under course policy — happy to walk through it in an interview.
